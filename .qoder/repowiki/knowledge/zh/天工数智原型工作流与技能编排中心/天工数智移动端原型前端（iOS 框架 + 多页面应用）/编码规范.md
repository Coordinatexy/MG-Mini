- 页面通过 data-* 属性（data-tab-panel、data-panorama-tab、data-message-panel、data-filter-option 等）声明式绑定交互逻辑，JS 侧通过 querySelectorAll('[data-xxx]') 统一查找并处理。
- 可访问性遵循 ARIA 规范：按钮使用 aria-expanded/aria-selected/aria-pressed，弹窗使用 role="dialog" aria-modal="true"，动态内容使用 aria-live="polite"。
- 通用 UI 组件（企业/站点选择器、日期选择器、筛选面板）通过工厂函数 createBottomSheetSelector 配置化创建，返回 open/close/setValue/getValue 等统一 API。
- 跨页面状态共享通过 sessionStorage 的固定键名（mg-mini-site-context）存储 JSON，并在页面加载时通过 restoreSiteContext 恢复。
- CSS 采用 BEM 风格命名（如 picker-sheet__header、microgrid-flow-card__icon），并通过 :root CSS 变量集中管理品牌色、字号、Vant 主题覆盖。
- 响应式行为通过 @media (max-width: 768px) 断点统一处理，移动端隐藏 iOS 装饰元素（status-bar、dynamic-island、home-indicator），全屏适配 ios-screen。
