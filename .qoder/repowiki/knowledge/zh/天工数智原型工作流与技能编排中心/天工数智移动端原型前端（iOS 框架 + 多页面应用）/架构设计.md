模块采用纯静态多页应用结构：每个业务页面（index.html、function.html、message.html、workbench.html 及各 function-*.html）独立加载自身 CSS 与 JS；全局样式集中在 css/global.css，各页面样式按功能拆分到 css/function-*.css。JS 以单文件模块化组织：common-selector.js 提供通用的底部弹窗选择器工厂 createBottomSheetSelector，被 index.js、function-*.js 复用；panorama-monitor-chart.js 与 panorama-date-picker.js 通过 window.PanoramaMonitorChart / window.PanoramaDatePicker 暴露 API，供 index.js 在能量全景展开时按需初始化。数据层全部为内联 mock（如 messageData、enterpriseItems、siteOptionsByEnterprise），状态通过 DOM data-* 属性与 class 切换驱动，无框架依赖。vendor/ 目录引入 Vant 组件库与 ECharts 图表库，FontAwesome 图标由 vendor/fontawesome 提供。页面间通过 sessionStorage 的 mg-mini-site-context 键值传递企业/站点上下文，并通过自定义事件 mg-mini:message-site-change、mg-mini:index-site-change 实现跨页面状态同步。
