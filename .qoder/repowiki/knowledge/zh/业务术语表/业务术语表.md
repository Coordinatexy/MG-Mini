### 天工数智
- 定义：本项目的产品品牌名称，定位为「智能微网 / 零碳能源管理平台」，面向能源运维人员与企业能源管理员提供站点监控、告警、策略等功能。
- 别名：天工数智平台

### 能量全景
- 定义：概览页中的核心业务模块，包含「能流视图」（拓扑实时功率/SOC）与「监控视图」（时序趋势曲线），支持横屏放大细读与日期查询。
- 别名：能量全景看板、微网能量全景

### 能流视图
- 定义：能量全景中的一种展示模式，以四节点拓扑（光伏/电网/储能/负载 + 中心微网）呈现实时功率流向与 SOC，含流向动画，已上线能力。
- 别名：能流拓扑、拓扑视图

### 监控视图
- 定义：能量全景中的另一种展示模式，以时序曲线展示近 3 小时（默认窗口）或历史某日的功率/SOC 数据，支持图例显隐与时间轴缩放。
- 别名：监控时序、趋势视图

### 未恢复 / 已恢复
- 定义：消息页两个分段 Tab，分别展示当前仍活跃的告警与已关闭并带恢复时间的告警记录；角标为 0 时隐藏。
- 别名：未恢复告警、已恢复告警、未恢复Tab、已恢复Tab

### 企业 / 站点切换
- 定义：消息页与能量全景共用的上下文切换机制：顶部选择器选企业，内容区选择器选站点，切换后列表/数据刷新并按默认条件重置。
- 别名：企业站点切换、上下文切换

### 下拉刷新与分页
- 定义：消息页的数据交互规范：下拉触发重新请求第 1 页，上拉按 20 条/页加载更早记录，默认数据范围为近 30 天。
- 别名：分页加载、下拉刷新

### 横屏放大
- 定义：能量全景中点击按钮进入全屏横屏 Overlay，用于细读图表，支持 Esc 退出与完整图例展示。
- 别名：横屏Overlay、全屏放大

### 站点离线横幅
- 定义：当所选站点处于离线状态时，在概览页顶部展示的提示横幅，联动缓存数据展示与延迟提示。
- 别名：离线横幅、站点离线提示

### 三视角诊断
- 定义：prd-writer 技能的标准化流程步骤之一，从三个不同视角对需求进行诊断分析，是 PRD 产出的前置门禁。
- 别名：三视角、需求诊断

### 模式 A/B/C
- 定义：prd-writer 技能的三种交付模式：A 从零两版交付、B 评估改进、C 增量融合，对应不同的需求输入与产出策略。
- 别名：PRD模式、交付模式

### APP 壳原型
- 定义：带 iOS 或微信外框的移动端 H5 原型形态，由 vibepm-app-generator 生成，运行时资源闭环在 app/ 目录内。
- 别名：手机壳原型、设备框原型、小程序壳

### WEB 静态原型
- 定义：不带设备外框的企业官网/落地页等静态 HTML 原型，由 vibepm-web-generator 生成，HTML/CSS/JS 分离，资源本地化。
- 别名：静态站原型、WEB原型

### 视觉规范 tokens
- 定义：.style/ 目录下每套风格对应的 *-style.md 文件，定义色板、字体、圆角、层次、组件气质与克制原则等设计令牌，供 generator 产物对齐使用。
- 别名：style tokens、设计规范、视觉token

### Skill 工具
- 定义：AGENTS.md 规定的标准化技能加载机制，用户消息命中触发词后必须先通过 Skill 工具加载对应 SKILL.md 再执行，禁止跳过直接实现。
- 别名：技能工具、SKILL.md

### diagram-drawer
- 定义：diagram-generator 的子 Agent，负责将自然语言描述转换为 XML 绘图源文件，再由 render-diagram 脚本渲染为 PNG。
- 别名：绘图子Agent、diagram drawer
