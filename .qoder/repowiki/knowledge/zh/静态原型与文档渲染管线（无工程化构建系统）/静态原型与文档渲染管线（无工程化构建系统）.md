本仓库是一个以 HTML/CSS/JS 静态页面为核心的前端原型项目，**没有传统意义上的构建系统**（无 Makefile、Dockerfile、package.json、webpack/vite、CI 流水线等）。其“构建”本质是 **AI Agent 技能驱动的文档与原型生成 + 轻量脚本渲染** 的混合流程。

### 1. 使用的系统与工具
- **静态页面直接运行**：`app/` 下的 `.html`、`.css`、`.js` 文件无需编译，直接在浏览器或本地服务器打开即可预览。
- **图表渲染**：通过 `.agents/skills/diagram-generator/scripts/render-diagram.{sh,py,ps1}` 调用 draw.io API（默认 `https://draw.axuremart.com/api/export`），将 XML 源图转为 PNG/JPEG/SVG。
- **Word 文档导出**：通过 `.agents/skills/common/export-word.{sh,py,ps1}` 调用远程 `apiBaseUrl` 服务，将 Markdown + 图片打包为 `.docx`。
- **操作手册截图**：通过 `.agents/skills/pm-operation-manual/scripts/screenshot.{cjs,js}` 使用 Playwright / Puppeteer / puppeteer-core 自动登录并截取各页面，输出 PNG 及 Markdown 引用。
- **依赖管理**：截图脚本要求安装 `playwright` 或 `puppeteer`（npm 包），但仓库内未提供 `package.json`，需使用者自行安装。

### 2. 关键文件与位置
- `.agents/skills/diagram-generator/scripts/render-diagram.sh` — 图表渲染入口（bash，回退到 Python/curl）
- `.agents/skills/common/export-word.sh` — 统一 Word 导出入口（bash，优先调用 Python 实现）
- `.agents/skills/pm-operation-manual/scripts/screenshot.cjs` — 自动化截图脚本（Node.js，支持多浏览器驱动）
- `.agents/skills/config.json` — 全局配置（API 地址等）
- `AGENTS.md` — 总工作流规范，定义技能触发词、执行顺序与产出目录约定
- `app/` — 静态原型产物（HTML/CSS/JS/images/fonts/vendor）
- `docs/` — PRD、测试用例、操作手册等文档产物
- `.style/` — 预置视觉规范（`*-style.md` + `*-preview.html`）

### 3. 架构与约定
- **技能即构建步骤**：每个 `.agents/skills/{name}/SKILL.md` 定义一个可被 AI Agent 调用的“构建阶段”，如 `prd-writer` → `prototype-list` → `vibepm-web-generator` → `pm-test-cases` → `pm-operation-manual`。
- **产物目录约定**：PRD 产出 `docs/`，功能清单 `doc/`，WEB 原型 `web/`，APP 壳内原型 `app/`，截图 `docs/images/screenshots/`。
- **跨平台脚本策略**：所有脚本均提供多语言实现（bash/python/powershell），按优先级自动选择可用解释器。
- **外部服务依赖**：图表渲染和 Word 导出均依赖远程 API，通过 `config.json` 中的 `diagramApiUrl` 和 `apiBaseUrl` 配置。

### 4. 约束与规则
- **禁止跳过技能**：`AGENTS.md` 强制要求命中触发关键词后必须先加载对应 SKILL 再执行，不得直接写代码或改文件。
- **样式约束**：生成 WEB/APP 原型时必须遵循 `.style/` 中指定的 `*-style.md` 视觉 tokens，禁止 CDN 外链，资源必须本地化。
- **输出格式约束**：PRD 命名 `YYYY-MM-DD-<主题>PRD.md`，功能清单第 2 章必须为完整页面结构列表（按屏分段、每屏五项要点）。
- **截图环境约束**：截图脚本要求至少安装 Playwright 或 Puppeteer 之一，且需确保本机有 Chrome/Edge/Chromium（若用 puppeteer-core）。
- **无版本化构建**：仓库不包含版本号管理、发布流水线或制品归档机制，产物即为最终交付物。
