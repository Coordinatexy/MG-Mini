## 简介
本文件为 MG-Mini 的“反馈详情页”提供系统化、可落地的技术文档。重点围绕 function-feedback-detail.js 的数据展示与交互逻辑，涵盖：
- 反馈详情信息的动态渲染
- 富文本编辑器集成与实时预览
- 编辑模式下的数据绑定、变更检测与自动保存
- 与后端的数据同步策略、冲突解决与版本控制
- 文件上传、图片预览与附件管理
- 表单验证规则、错误处理与用户体验优化

### 数据展示与动态渲染
- 数据源优先级：后端详情 > 本地缓存 > 默认值
- 渲染流程：解析字段 -> 填充模板节点 -> 处理富文本内容 -> 生成预览片段 -> 附加列表渲染
- 关键职责：
  - 字段映射与类型转换
  - 富文本内容的转义与安全渲染
  - 空态与错误态的 UI 呈现

```mermaid
flowchart TD
```

### 与后端的数据同步、冲突解决与版本控制
- 同步策略：
  - 首次加载拉取详情，后续增量提交
  - 离线优先：本地缓存 + 队列异步同步
- 冲突解决：
  - 服务端版本号（ETag/Last-Modified/自定义 version）
  - 客户端检测到冲突时，提示差异合并或强制覆盖
- 幂等性：
  - 使用唯一请求 ID 避免重复提交
  - 服务端对同一请求幂等处理

```mermaid
sequenceDiagram
participant C as "控制器"
participant S as "存储"
participant API as "后端API"
C->>API : GET /feedback/{id}?version=...
API-->>C : 返回详情+version
C->>S : 写入缓存
C->>API : PUT /feedback/{id} (payload, version)
alt 无冲突
API-->>C : 200 OK + newVersion
C->>S : 更新version
else 冲突
API-->>C : 409 Conflict + serverVersion
C->>C : 提示差异/合并策略
C->>API : 重新提交(合并后)
end
```

- 附件管理：
  - 排序、重命名、删除、替换
  - 断点续传与失败重试
  - 多端一致性（云端与本地列表同步）
