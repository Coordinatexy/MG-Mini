# 需求：告警迁移引导弱提示（概览页）

## 1. 背景与目标

**背景：** 新版本中，原【功能】模块下的"故障告警"、"事件告警"已迁移并合并至【消息】模块统一查看。

**目标：** 在版本发版后，用户首次进入概览页时，以弱提示形式告知入口变化，降低找寻成本，避免用户误认为功能下线。

## 2. 适用范围

- 端：微信小程序
- 页面：概览页（index / home-screen）

## 3. 前置条件

1. 用户已登录并进入概览页；
2. 用户此前未点击过本提示的"不再提示"（以本地标记为准，版本号隔离，新大版本可重新引导一次）。

## 4. 功能描述

### 4.1 触发时机

- 进入概览页完成首屏加载后延迟约 0.6s 弹出；
- 能量全景处于横屏放大态时不弹出；
- 非概览页（消息、功能、工作台）不触发。

### 4.2 展示内容与样式

- 形式：非模态底部气泡弱提示，不阻断页面浏览与滑动，仅气泡本身可点击；
- 位置：底部 Tab 栏上方，气泡带小箭头指向【消息】Tab，同时【消息】Tab 显示红色呼吸圆点；
- 文案："功能入口调整：原功能模块的故障告警、事件告警已迁移并合并至【消息】，请前往消息模块统一查看。"，其中【消息】高亮；
- 按钮：
  - "前往查看"（主按钮）：跳转至消息页；
  - "不再提示"（次按钮）：永久关闭本引导；
  - 右上角"X"：关闭本次提示。

### 4.3 交互与消失逻辑

| 操作 | 行为 |
|---|---|
| 点击"前往查看" | 关闭本次气泡，携带当前企业/站点上下文跳转至消息页；下次进入概览页仍可再次展示（直到点击"不再提示"） |
| 点击"不再提示" | 写入本地"不再展示"标记，关闭气泡；之后进入概览页不再展示 |
| 点击右上角"X" / 按"Esc" | 仅关闭本次，下次进入仍展示 |
| 无操作 10s | 自动淡出关闭，仅关闭本次，下次进入仍展示 |
| 跳转/刷新/重进概览页 | 如未标记"不再提示"，每次加载均重新展示，便于感知与演示 |

### 4.4 异常兼容

- 本地存储不可用时，降级为"仅本次关闭"，不阻断页面及跳转；
- 关闭/跳转过程异常时，优先保证页面可用，不抛错、不卡死。

## 5. 验收标准

1. 首次进入概览页，约 0.6s 后底部出现气泡，箭头指向【消息】且有红点呼吸动效；
2. 文案与按钮（前往查看 / 不再提示 / X）与设计一致；
3. 点击"前往查看"正确跳转消息页，且企业/站点上下文保持一致；
4. 点击"不再提示"后，刷新/重进概览页不再出现；清除本地标记后可复现；
5. 点击"X"、"Esc"或等待 10s 自动消失后，刷新页面可再次出现；
6. 在消息/功能/工作台页不出现；能量全景横屏放大时不出现；
7. 弱提示不遮挡弹窗操作，页面仍可正常滑动。

## 6. 备注

- 本地标记 Key 需带版本号（如 ...:v1），发大版本时递增版本号即可实现"新版本重新引导一次"；
- 建议后期补充点击/跳转埋点，用于评估引导到达率。
